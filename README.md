# fmlcore

> **Life sent a plot twist. We built a core for it.**

**fmlcore** is an open-source survival kit for beautifully chaotic humans: sarcastic tools, honest reflection, and tiny systems for the moments when life says “FML.” It is a public, community-built space for turning the spiral into something useful—without pretending everything is fine.

## What fmlcore is for

- Building small, practical tools for self-reflection, wellbeing, and personal growth.
- Sharing ideas with heart, humour, and enough structure to make them usable.
- Creating in public: fork it, improve it, and send a pull request when your change is ready.

## Local setup

fmlcore is deliberately **documentation-first** right now: there is no application runtime or deployment target yet. You can still clone the project, explore it locally, and contribute immediately.

```bash
git clone https://github.com/naveenSaini1/fmlcore.git
cd fmlcore
git checkout -b docs/your-change
```

Make your change, keep it focused, and follow the contribution guide before opening a pull request. When we add an executable component, that pull request must include its exact local-run and deployment instructions.

## How to contribute

1. Read [CONTRIBUTING.md](CONTRIBUTING.md).
2. Fork the repository and create a focused branch.
3. Make a useful change—code, writing, design, documentation, or a better idea.
4. Use a clear commit message, then open a pull request.

Everyone can propose changes through forks and pull requests. Direct pushes to the default branch remain owner-controlled so the project stays reviewable.

## Commit convention

We ship in stages. Each completed stage gets a clear, conventional commit message:

```text
feat(core): add daily reset prompt
docs(readme): clarify local contribution setup
fix(ui): handle empty reflection entries
```

Use `type(scope): short summary`. See [CONTRIBUTING.md](CONTRIBUTING.md) for the full guide.

## A small note on wellbeing

fmlcore is a creative community project, not medical, mental-health, or crisis advice. If you are in immediate danger or need urgent support, contact local emergency services or a qualified professional.
